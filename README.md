# homebrew-tap

Homebrew formulae for tools by 7milch. The files under `Formula/` are written by each tool's release workflow; do not edit them by hand.

```sh
brew install 7milch/tap/caljp
```

| Formula | What it is |
|---|---|
| [caljp](https://github.com/7milch/caljp) | BSD `cal` clone that colors Japanese holidays |
